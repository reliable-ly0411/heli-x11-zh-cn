- 固定显示类由 38 增至 50：控制器/音频错误提示、图形质量、全部类型筛选、作者/版本字段、演示版限制、收藏菜单和无动力模型筛选。
- 修正 OpenGL 大小写、近/远裁剪距离、回放速度/进度/片段起点/片段终点。
- 修复正式版 .NET 构建：CLR 程序集版本不允许末段 65535，因此内部程序集标识与对外 PE/ProductVersion 分离。
- Windows 11.0.2675 与 Linux 11.0.2681 的白名单字符串均逐项匹配。Java 指令不改写，目录名、模型和录像内容、作者信息保持原样。
