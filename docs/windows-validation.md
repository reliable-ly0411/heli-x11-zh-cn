# Windows 安装器验收范围

## 上游基线

- 官方来源：<https://www.heli-x.info/2675/setupHeli-X11_win64.exe>（官网 Windows x64 下载入口）。
- 上游版本由 JAR 内版本字符串确认：11.0.2675。
- 原安装包 SHA-256：`87ac36b347fe31c00d4762a596a6b7fd64f5b0f3c141dfaea57f55c5cb75177b`。
- 其主 JAR 与 Linux 11.0.2681 不同，因此使用独立兼容表；未将 Linux 哈希直接套到 Windows。
- 1,272 个原语言键均有译文，50 个类的目标字符串全部存在，构建后验证 13 组字体、图集引用、ZIP 完整性及保持程序指令不变。

原安装包、解包文件、测试夹具和生成的中文 JAR 均留在私有验证环境，不作为发布内容。

## 已完成的测试

在 Windows 10 x64 的独立测试目录使用实际编译的 EXE，针对官方原资源与合成设置测试：

- 中文、空格、`&` 路径。
- 写保护导致安装中途失败时，原文件恢复、首次安装状态目录清理。
- 全新安装、校验、重复安装、首次备份保留。
- 备份损坏时拒绝卸载，保留安装状态。
- 实际运行 PowerShell 校验与 BAT 启动段：原文件匹配时加入中文 JAR；模拟更新后停用。
- 更新后拒绝安装/校验，但仍可卸载。
- 卸载后 BAT 与语言列表字节级恢复，用户后来修改的其他设置保留。
- 安装器窗口在 Windows 上绘制并检查了中文文案、目录选择和三个操作按钮。

Linux 的 4 项原测试、2 项 Windows 适配器单元测试及原 Linux 安装/恢复集成测试通过。Windows 的更多进程与分离目录用例由 `tests/windows_installer.ps1`、`tests/windows_split.py` 提供；发布说明记录最终制品实际执行结果。

## 模拟器内运行检查

环境：Windows 10 x64，1600×900 桌面，HELI-X 11.0.2675 官方演示版，独立完整资源副本。未改动授权限制，未分发原版资源。采用活动用户会话运行，Guest Agent 静默截图检查实际画面。

修订候选已检查：

- 主要菜单、无控制器错误提示、飞行模式（舵量、指数、死区、总距、油门、前馈）。
- 全局设置的性能、OpenGL、其他页；水面质量选项及近/远裁剪距离术语。
- 飞行记录列表、作者/版本字段、全部类型与 Demos 分类筛选。
- 官方 Kraken-3d-demo 在 MVA-Almere 场景加载、播放、暂停、跳转、变速、停止；连续截图证明模型运动，暂停后画面与进度保持一致。
- 回放面板“播放速度/播放进度/片段起点/片段终点”显示完整，无截断或按钮重叠。

显卡诊断：直通 RTX 3060 Laptop GPU 驱动正常；匹配 HELI-X Java PID 的 NVIDIA OpenGL 模块、GPU 3D 引擎计数、约 304 MiB 独占显存及实际渲染画面均有证据。已观察标题帧率约 149–151 FPS（测试设置上限 150）。未仅凭虚拟机配置或任务管理器默认曲线推断显卡使用。

发现并修正：缺少控制器/音频驱动的固定提示、图形质量选项、回放元数据、演示版场景/机型限制提示，以及裁剪距离和回放片段端点术语。固定标签白名单从 38 增至 50 类，Windows 和 Linux 的目标字符串均逐项匹配。原 Java 指令与三个原资源保持不变。

## 已知限制与未验范围

- 未连接控制器：未验证真实摇杆、校准和手动操纵飞行；录像回放不能替代这些测试。
- 原版与汉化版日志均出现 OpenAL 初始化失败。此环境未通过音频输出验收；未将原版同样存在的问题归为汉化回归。
- VR、Windows 11、ARM64、其他 HELI-X 构建、不同缩放倍率与多显示器切换未验。
- 官方注册表中的真实安装实例未验；分离目录测试使用模拟注册表，不能冒充真实安装实例。
- 未穷举所有窗口、训练和联机功能；模型作者说明、官方 PDF、许可与部分非核心文案不在汉化范围。
- 安装器未签名。

## 最终制品门槛

上述模拟器检查来自修订候选。发布前须使用干净提交构建的最终 EXE，再跑 Windows 安装/恢复用例并安装到模拟器复验；不得用候选资源测试代替最终原包验收。最终提交、SHA-256、结果及未验范围记录于正式 Release 与后续验收记录，发布后重新下载校验，旧测试版保留。
